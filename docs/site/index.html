01 / מחיבור של מחשבות לסגירת קצוות

לא עוד חלון שיחה.
מקום לדברים שחשובים לך.

אותם נתונים זמינים בשיחה ובמסכים ייעודיים. אפשר לבקש מהאייג׳נט, ואפשר פשוט לערוך בעצמך.

הצילומים הם נכסי הדגמה קיימים ב־docs/screenshots. הממשק הנוכחי עשוי להיות שונה. אין כאן מידע אישי חי.

02 / מבנה שאפשר להבין

הנתונים שלך.
תשתית שאפשר לעקוב אחריה.

הדפדפן פונה ל־Pages. בקשות מאומתות מגיעות ל־Worker פרטי ולאייג׳נט של בעל החשבון. SQLite שומרת את המידע; שעונים עמידים מפעילים את השגרות.

הכניסהדפדפן / PWAמסכי React ושיחה זורמת
←
הגבול הציבוריCloudflare PagesHTTPS · Session · CSRF
←
הסביבה של בעל החשבוןWorker + AgentAPI · כלים · SQLite · שעונים
פנימיהמידע האישישיחות, משימות, פתקים וזיכרונות
בקשות מודל ↔ספק AI שנבחרהקשר רלוונטי נשלח לספק
כלים חיצוניים ↔OpenConnectorחשבונות מחוברים ופעולות באישור
↳

״בענן שלך״ אינו ״ללא העברת מידע״. בקשות AI שולחות הקשר לספק שבחרת. חיבורים שולחים מידע לשירות החיצוני. Talorys אינו מוצר local-only; חשוב לבחור ספקים והרשאות בהתאם לצרכים שלך.

03 / מנוע פרואקטיבי — שני שלבים

תזכורת טובה.
לא פעולה מפתיעה.

המנוע עובד בשני שלבים: שלב 1 — סריקה על בסיס כללים, ללא AI, עם deduplication לפי signal_hash ו-TTL. שלב 2 — קריאת AI אחת ומתוקצבת לכל סריקה: המודל מדרג את ההצעות לפי דחיפות ומצרף הצעת פעולה אחת לכל משימה.

ההצעות כבויות כברירת מחדל. אם המודל לא זמין — המנוע ממשיך עם דירוג הכללים בלבד. שגיאה ב-AI לא עוצרת את הסריקה.

  1. 1
    מגלים אות רלוונטי

    משימה שמועד היעד שלה עבר, ב-24 שעות הקרובות, או שעברו עליה 3 ימים ללא עדכון.

  2. 2
    AI מדרג ומציע פעולה

    קריאה אחת, 15 שניות timeout, Zod validation על הפלט. שגיאה → fallback לדירוג בסיסי.

  3. 3
    מציגים הצעה, לא מבצעים

    deduplication, TTL, שעות שקט — ואז הפעמון מוצג. כפתור "אישור" פותח טיוטה בצ׳אט.

Talorys על המסך,
בכל אפליקציה.

05 / מדריך התחלה

מהרגע הראשון,
ברור מה לעשות.

צריך חשבון Cloudflare ו־Node.js בגרסה 22 ומעלה. ההתקנה יוצרת סביבת בעלים יחיד. שירותי ענן ומודלים כפופים למכסות ולתמחור שלהם.

המסלול הרגיל

להתקין בחשבון שלך

המתקין המפורסם ב־npm מוביל אותך בהקמה. תיקוני הסקירה מ־25.10 נמצאים בקוד המקור; אין כאן טענה שהם כבר כלולים בגרסת npm או בפריסה חיה.

npx create-talorys@latest

למדריך ההתקנה המלא ↗
רוצה דווקא את קוד הסקירה?

יש לשכפל את הריפו, להתקין עם npm ci ולהריץ את הבדיקות. ראה README להפעלה מקומית. אין צורך לחבר חשבון אמיתי כדי לנסות את מצב ההדגמה.

01 לקבוע בסיס בטוח

הגדר סיסמת בעלים ואזור זמן. היכנס לכתובת שהמתקין החזיר, ובדוק שהגישה דורשת התחברות. אל תשתף טוקנים או סיסמאות בצ׳אט.

02 ליצור את המשימה הראשונה

במסך Tasks הוסף משימת בדיקה עם מועד יעד. לאחר מכן בקש בצ׳אט להוסיף משימה נוספת. בדוק את התוצאה ברשימה, לא רק את ניסוח התשובה.

03 לבחור מודל ולבדוק זיכרון

ב־Settings בחר ספק ומודל. אפשר להגדיר שרשרת גיבוי. בקש לזכור העדפה לא רגישה, פתח Memory וודא שהיא נכונה. אפשר לערוך או למחוק אותה.

04 לחבר שירות באופן מודע

OpenConnector דורש הגדרת סביבת שרת. במסך Connections בדוק סטטוס והשלם את ההסכמה של השירות. ניהול הרשאות מפורט לכל פעולה וניהול שרתי MCP שרירותיים עדיין לא הושלמו.

05 להפעיל שגרות והצעות

צור תזכורת קרובה ב־Automations. אם קוד הסקירה נפרס, אפשר להפעיל Proactive בהגדרות ולקבוע מרווח ושעות שקט. בדוק את היסטוריית הריצות והפעמון. ריצות AI עשויות לצרוך מכסה.

06 לגבות לפני שמרחיבים שימוש

ייצוא הנתונים שומר את ישויות הליבה, אך אינו גיבוי מלא של חשבון הענן. הוא אינו כולל סודות, סשנים, הצעות, יומן פעולות או את כל נתוני האבחון. יש לשמור גם את קוד המקור והגדרות התשתית באופן בטוח.

06 / שקיפות במקום הבטחות
